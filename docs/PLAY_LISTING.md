## העלאת AAB לבדיקה פנימית

1. התקינו Android Studio + JDK 21 אם עדיין אין.
2. יצירת מפתח העלאה (פעם אחת, לשמור במקום בטוח):

```bash
keytool -genkeypair -v \
  -keystore android/upload-keystore.jks \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias upload
```

3. העתיקו `android/keystore.properties.example` אל `android/keystore.properties` ומלאו סיסמאות.
4. בילד:

```bash
npm run cap:sync
cd android && ./gradlew bundleRelease
```

הקובץ: `android/app/build/outputs/bundle/release/app-release.aab`

5. Play Console → בדיקה פנימית → יצירת גרסה → העלאת ה-AAB → הוסיפו את עצמכם כבודקים.
